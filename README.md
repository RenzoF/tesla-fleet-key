# tesla-fleet-key

GitHub Pages site for `tesla.rlt.onl`. It publishes only the **public** key that Tesla's Fleet API
requires at `/.well-known/appspecific/com.tesla.3p.public-key.pem` for a private Home Assistant
(`tesla_fleet` integration). The private key never leaves Home Assistant (`config/tesla_fleet.key`).
Documented in the private home-lab repo, `home-assistant/README.md`.
